What Ete reads

Most consonants draw one visible symbol. Vowels usually tell Ete how those symbols connect or turn; they are instructions rather than extra symbols.

Start with s. for one symbol. Then try sat. for two symbols joined in one path.

One sentence, one path

Ete reads an ordinary path from left to right, then top to bottom. Punctuation or a new line begins a new path.

A period adds the small finishing dot. A comma separates paths without that dot.

The symbol families

Each pair shares a basic shape. The first is static; the second is its dynamic partner:

ğ / h g / c l / r v / f d / t b / p s / z ş / ç n / m.

Keep this window open and type in the editor beside it. The drawing updates as soon as the sentence is valid.

Use a as glue

Put a before the next consonant when it continues the same branch. In sat, s comes first and t continues after it.

The a itself does not add another symbol.

Turn a symbol

An acute vowel turns the element it introduces by 90°. Compare s with ás.

When typing, press ` after a vowel to add the acute: a`→á.

Three special elements

ã is a visible long line, not glue. y and w are side branches and therefore only belong inside a fuseau.

A branch is simply a sequence of symbols. Build this comfortably before moving on to parallel branches.

Put two branches in parallel

When both branches are one plain element, write ơ between them. For example, rơt places branch r beside branch t. Together they form one fuseau.

This shorthand contains no other vowel. Use accented ớ when the right-hand element is oriented: zớc. When a plain series follows, retain the closing o, as in zớcons.

Add a third branch

While learning, use the fully framed form elroto: e opens the fuseau, l, r, and t are its branches, and o marks the later boundaries.

Put a fuseau inside another

Wrap an inner fuseau in apostrophes and keep its full frame: 'esto'. Quoting tells Ete exactly where the inner structure begins and ends.

Use full e/o framing until the structure feels natural. The shorter spellings on the next page are optional.

The simple rule

In a complex fuseau, drop the opening e only when the fuseau starts a path or follows another fuseau. Drop the final o only when it ends a path or comes before another fuseau.

ơ is already complete

rơt is not an omitted version of a longer spelling. It is a special complete form for exactly two plain, single-element branches. Do not write erơto.

Safe complex short forms

elroto, elrot, lroto, and lrot describe the same standalone fuseau.

Keep the boundary beside plain symbols

A simple AơB or AớB pair before plain symbols keeps its closing o. Richer fuseaux retain the e/o boundaries needed to show where they end.

Adjacent and nested fuseaux

Adjacent simple fuseaux may be written rơt sơt. Each ơ still joins only its two neighboring elements.

Nested fuseaux never use ơ: keep the inner binary fuseau fully framed as 'esto'.

When both branches are nested binary fuseaux, their middle apostrophe is shared: e'etmo'etmo'o.

One orientation exception

If the first branch begins turned, keep the accented opening é. Write éğarhom, not áğarhom.

You never have to abbreviate. The explicit spelling is the safest choice, and Ete’s serializer shortens it only when the result stays unambiguous.

Draw a gate

In isut, i marks s as the source and u connects the later t as its target.

Every opened source needs a target. Repeat the source marker when one element must connect to more than one target.

Typing shortcuts

Vowels: ae→ẽ ao→õ ei→ĩ oi→ị oe→ẹ eu→ư eo→ơ ou→ũ aoe→ȡ.

Consonants: sh→ş ch→ç gh→ğ. After a vowel, ` adds acute, - grave, and = macron. For a, the macron is written ã; a second acute produces ả = á + á.

The serializer ignores vowel order inside a registered combination and always abbreviates it: éá / áé → ẻ.

When Ete reports an error

Read the message below the editor. The most common fixes are to restore a missing e/o boundary, move y/w into a fuseau, or finish an open gate.

Write on the third axis

Turn on 3D, then place two acute accents before an element. One accent selects the second axis; two select the third. Compound spellings retain both accents—for example, smỏt uses ỏ = á + ó to put t on the third axis. When both accents are acute, write the compact form ả = á + á.
